## 3. 묶는 규칙

- [x] 3.1 겹침 비율로 잇고 연결 요소로 묶던 계산을 걷어 내고, 범주로 묶는다 ("업무 범주가 묶음을 정한다")
- [x] 3.2 묶음마다 필수 단계와 옵션 단계를 가르고, 키를 필수 단계로 만든다 ("묶음의 필수 단계와 키")
- [x] 3.3 결정된 프로세스를 고정 묶음으로 깔고, 사례를 범주·필수 단계 순으로 붙인다 ("결정된 프로세스의 경계를 지킨다")
- [x] 3.4 범주가 없거나 필수 단계를 하나도 갖지 않은 사례를 `unclassified` 로 뺀다 ("범주를 가리지 못한 사례를 따로 돌려준다")
